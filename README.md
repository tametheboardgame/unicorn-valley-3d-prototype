# Unicorn Valley 3D Prototype

Experimental tablet-first 3D vertical slice of Unicorn Valley.

This repository is separate from the existing 2D game and is intended to test the technical, visual and performance viability of a high-quality stylised 3D version.

## Objective

Determine whether a one-person, AI-assisted development workflow can produce a polished stylised 3D Unicorn Valley experience that runs well on a tablet and is practical to expand.

The initial target is a small vertical slice of Sunbeam Village featuring Nova, third-person movement, representative environments, several NPCs, an interaction, an interior and a small gameplay activity.

The primary technical success criterion is a recognisable and attractive Sunbeam Village running on the agreed target tablet at a stable 30 FPS or better.
